# shiny-winner

A full-stack app for managing a hotel.

You can look at your hotel's KPIs and other metrics, view a calendar with all guest reservations, check-in/check-out guests, manage housekeeping & maintenance, produce and send invoices, and much more.

There are four roles: Admin, Manager, Receptionist, and Housekeeper. Each role has separate permissions, particularly on which pages and actions are available to them. (Admins have all permissions, housekeepers have the least)

Test accounts are provided with the following emails for each role:
- Admin: admin@hotel.test
- Manager: manager@hotel.test
- Receptionist: receptionist@hotel.test
- Housekeeper: housekeeping@hotel.test
These all share the same password (not posted here obviously, but you can ask me if you want it).

## Project Details

This app uses Next.js via `npx create-next-app@latest`.

All data (including accounts) is automatically generated by a mock data seeder (`\prisma\seed.ts`).

Uses Supabase for backend database. As Supabase automatically pauses projects after a while of inactivity, this app will throw 500 server errors after that period has elapsed.
